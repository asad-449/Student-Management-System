# Student Management System

## Overview

This project is a console-based Student Management System developed in C++.

The system allows users to manage student records through a menu-driven interface and stores data using file handling for persistent storage.

## Features

* Add Student Record
* Display Student Records
* Update Student Information
* Delete Student Record
* File Handling for Data Storage
* Menu-Driven Interface

## Technologies Used

* C++
* File Handling
* Object-Oriented Programming

## Project Structure

```text
Student-Management-System/
│
├── main.cpp
├── students.txt
└── README.md
```

## Expected Outcome

A functional application that allows users to add, update, delete, and display student information with persistent data storage.
